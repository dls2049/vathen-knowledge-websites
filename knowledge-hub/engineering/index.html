自动化任务桥接路线

  1. 服务端使用 Secret 管理 Notion API Token，绝不暴露到前端。
  2. 通过最小权限集成读取目标数据库，并按明确规则更新任务状态。
  3. 增加操作者身份、审计日志、幂等键、并发锁与失败重试。
  4. 对完成判定设置可验证条件；Agent 可自主标记，但必须留下证据与日志。
  5. 前端展示 API 返回的更新时间与数据来源；服务不可用时明确显示状态未知。
